隐私政策

最后更新：2026 年 6 月

核心承诺：OpenCode Mobile 不收集、不上传、不共享你的任何个人数据。 所有信息仅存储在你的设备本地。

1. 我们收集什么信息

OpenCode Mobile 仅在你的设备本地存储以下信息，不会上传到任何服务器：

  • 服务器连接配置（主机地址、端口、用户名）
  • SSH 认证凭据（密码或 PEM 私钥）——使用系统级加密存储（Android Keystore）
  • 工作目录路径偏好设置

2. 我们不收集什么

  • 不收集设备标识符、位置信息或个人身份信息
  • 不收集 AI 对话内容
  • 不收集使用统计或崩溃报告
  • 不使用任何第三方分析 SDK

3. 数据如何存储

SSH 密码和私钥使用 Android Keystore（硬件级安全存储）加密保存， 其他配置使用系统加密存储，均无法被其他 App 读取。

4. 网络连接

App 仅通过 SSH 协议连接到你自己配置的服务器， 不连接任何第三方服务或云服务器。AI 对话直接在你的服务器上处理， 不经过我们的任何中间服务。

5. 数据删除

卸载 App 即可删除所有本地存储的数据。 你也可以在 App 内删除各服务器配置，相关凭据会立即从设备中清除。

6. 儿童隐私

本 App 面向开发者，不面向 13 岁以下未成年人。

7. 政策变更

如我们更新隐私政策，将在此页面更新日期并通知用户。 继续使用即表示同意更新后的政策。

8. 联系我们

如有隐私相关问题，请通过 GitHub Issues 联系： github.com/Zhucan123/opencode-app/issues
